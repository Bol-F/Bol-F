## Selected Work

### [TradeGraph AI](https://github.com/Bol-F/trade-ai)
International-trade intelligence platform for exploring trade flows, country and product profiles, concentration indicators, anomaly signals, forecasts and explainable supplier recommendations.

`Python` `Django REST Framework` `PostgreSQL` `Polars` `PyArrow` `Redis` `Celery` `scikit-learn` `Next.js` `Docker`

**Engineering:** resumable ingestion, Parquet processing, Isolation Forest anomaly detection, forecasting, role-based authentication, metrics, structured logging, automated tests and production-oriented security controls.

---

### [PulseNLP](https://github.com/Bol-F/NLP-classifier)
Three-class sentiment analysis system for **negative / neutral / positive** text with reproducible data preparation, model evaluation and a Django-based inference API.

`Django 5` `DRF` `scikit-learn` `PyTorch` `Hugging Face Transformers` `Next.js` `TypeScript` `OpenAPI`

**ML:** seven-source dataset pipeline, calibrated ensemble, Transformer fine-tuning path, batch inference, difficult-case evaluation suite and measured model metrics.

---

### [Telecom Customer Churn MLOps](https://github.com/Bol-F/boraq-task2)
End-to-end ML workflow that trains and compares churn models, tracks experiments, validates model quality and serves the approved model through an API.

`Python` `scikit-learn` `MLflow` `Django REST Framework` `pytest` `Docker` `GitHub Actions` `Next.js`

**MLOps:** reproducible training, MLflow experiment tracking, ROC-AUC quality gate, CI, guarded scheduled retraining and deployed frontend/API.
