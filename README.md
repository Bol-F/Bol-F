## Featured projects

### 🌍 [TradeGraph AI](https://github.com/Bol-F/trade-ai)
**International-trade intelligence platform** that turns BACI-compatible data into searchable country/product profiles, maps, concentration indicators, anomaly signals, forecasts and explainable supplier recommendations.

`Python` `Django REST Framework` `PostgreSQL` `Polars` `PyArrow` `Redis` `Celery` `scikit-learn` `Next.js` `TypeScript` `Docker`

**Highlights:** resumable data ingestion, Parquet processing, Isolation Forest anomaly detection, forecasting, role-based auth, metrics, structured logs, tests and production-oriented security controls.

---

### 🧠 [PulseNLP](https://github.com/Bol-F/NLP-classifier)
**Three-class sentiment analysis platform** for negative / neutral / positive text with a reproducible multi-source training pipeline and Django model-serving API.

`Django 5` `DRF` `scikit-learn` `PyTorch` `Hugging Face` `Next.js` `TypeScript` `OpenAPI`

**Highlights:** seven-source dataset pipeline, calibrated sklearn ensemble, Transformer fine-tuning path, batch inference, difficult-case evaluation suite and measured model metrics.

---

### 📊 [Telecom Customer Churn MLOps](https://github.com/Bol-F/boraq-task2)
**End-to-end ML delivery project** that trains and compares churn models, tracks experiments, applies a model-quality gate and serves the approved model through an API.

`Python` `scikit-learn` `MLflow` `Django REST Framework` `pytest` `Docker` `GitHub Actions` `Next.js`

**Highlights:** reproducible training, MLflow tracking, ROC-AUC quality gate, CI, scheduled guarded retraining and deployed frontend/API.
